# kenya-county-population-analysis

I'm working on a new data project: analysing Kenya's 2019 census population by county using Python and SQL.

So far I have:
✅ Cleaned the data with pandas (column names, numeric conversion, missing values, duplicates)
✅ Checked that male + female + intersex = total for every county
✅ Written SQL queries on the most and least populous counties, each county's share of the national population, and the male-to-female ratio

Still to come: charts and a summary of key findings.

This is a work in progress and I'd welcome feedback.

GitHub: https://github.com/Patrick001-DA/kenya-county-population-analysis
